# 의심 문자 판별기

받은 문자가 보이스피싱·스미싱인지 헷갈릴 때, 문자를 붙여넣으면 **위험도와 대처법**을 알려 주는 웹 도구입니다.
HTML 파일 1개(`phishing.html`)로 만들었고, AI 판단을 위한 서버 함수 1개(`api/judge.js`)가 있습니다.

- **사용해 보기**: https://asdf-a-46fe.vercel.app/phishing.html
- **대상**: 사기 문자를 받고 진짜인지 헷갈리는 일반인 (특히 중장년·어르신과 그 가족)
- **참고용입니다.** 100% 정확하지 않고, 새로운 수법은 놓칠 수 있습니다.

## 사용 방법
1. 의심되는 문자를 입력창에 붙여넣고 **판별하기**를 누릅니다.
2. 결과에서 **위험도(🟢 안전 / 🟡 주의 / 🔴 위험)**, **추정 사기 유형**, **의심되는 이유**, **해야 할 행동**을 봅니다.
3. 문자에 전화번호가 있으면 **번호 카드**가 나옵니다. `📞 더콜에서 확인`, `🔍 구글/네이버에서 검색` 버튼으로 번호의 신고 이력을 직접 확인합니다.
4. 더 확인하고 싶으면 아래쪽 **AI 보조 판단**에서 동의에 체크하고 **AI에게 물어보기**를 누릅니다. (키 입력 없이 쓸 수 있습니다.)

## 주요 기능
| 기능 | 설명 |
|---|---|
| 규칙 기반 판별 | 기관 사칭, 돈 요구, 인증번호 요구, 링크, 택배·가족 사칭 등 위험 신호를 점수(0~100)로 계산 |
| 사기 유형 표시 | 택배 사칭형, 가짜 결제 알림형, 개인정보 유출 보상 사칭형 등 |
| 의심 부분 표시 | 문제가 되는 단어와 링크를 노란색으로 표시 |
| 전화번호 확인 | 번호 종류(휴대폰·인터넷전화·대표번호 등) 안내 + 더콜·구글·네이버 검색 버튼 |
| AI 보조 판단 | 규칙이 놓치는 새 수법을 AI가 한 번 더 판단하고 규칙과 나란히 비교 |
| 종합 판정 | 규칙과 AI 중 **더 조심스러운 쪽**을 보여 줌 (AI가 더 정확하다고 가정하지 않음) |

## 개인정보와 AI
- AI에 보내기 **전에** 이름, 전화번호, 계좌번호, 주민번호, 카드번호, 이메일, 링크 뒷부분을 **자동으로 가립니다.** (전화번호는 `[전화번호 070]`처럼 종류만 남깁니다.)
- 가린 모습을 화면에서 **직접 확인**하고, **동의에 체크한 뒤 버튼을 눌렀을 때만** 전송합니다.
- 키를 넣지 않으면 이 사이트의 서버 함수(`api/judge.js`)가 서버에 숨겨 둔 키로 대신 물어봅니다. 서버는 문자를 저장·기록하지 않고, 한 번 더 개인정보를 가립니다.
- **OpenRouter 무료 모델만** 사용합니다. 무료 모델 제공사가 입력을 저장하는지는 확인하지 못했습니다.
- 직접 쓰고 싶으면 "내 OpenRouter 키로 직접 쓰기"에 키를 넣을 수 있습니다. 키는 저장하지 않습니다.

## 알려진 한계 (정직하게)
- **새로운 수법은 놓칩니다.** 규칙은 아는 단어와 패턴만 잡습니다.
- **정상 문자를 위험으로 보는 경우**가 있습니다. (예: 은행 안내 문자, 진짜 부고 문자)
- **AI 정확도는 아직 확인되지 않았습니다.** 정상 문자 오탐 측정이 끝나지 않았습니다.
- **무료 한도(하루 50회 정도)**가 있어서 한도가 차면 "AI가 바쁘다"는 안내가 나옵니다.
- 번호 검색은 **신고 이력을 대신 조회해 주지 않습니다.** 검색 결과가 없다고 안전하다는 뜻은 아닙니다.
- 규칙은 시험 문자를 보고 고쳤기 때문에, 아래 규칙 정확도는 실제보다 높게 나옵니다.

## 측정 결과 (2026-11)
| 구분 | 결과 | 주의 |
|---|---|---|
| 처음 12가지 규칙 | 사기 5/20, 정상 7/10 | 이게 더 정직한 숫자 |
| 규칙 보강 후 | 사기 20/20, 정상 10/10 | **같은 문자를 보고 고친 결과라 정확도로 쓰지 않음** |
| AI (Nemotron 3 Ultra, 무료) | 사기 17/18 | 정상 문자는 **아직 측정 못 함** |
| `openrouter/free` 자동 선택 | 30개 중 7개 응답 형식 오류 | 문자마다 다른 모델이 답해서 비교용으로 부적합 |

시험 문자는 언론 기사·은행 안내 페이지에서 인용한 사기 문자 28개와, 대부분 직접 작성한 정상 문자 18개입니다. 실제로 받은 정상 문자로 바꿔 다시 측정해야 합니다.
